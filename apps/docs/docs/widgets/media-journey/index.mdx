The media journey widget reconstructs a title's path across connected media services: **request → grab → download → import → library**.

It stays empty until:

1. You connect matching integrations such as Overseerr/Jellyseerr, Sonarr/Radarr, a download client, and a media server.
2. The **tasks** service is running the `mediaTraceCorrelation` job (see [Tasks](/docs/management/tasks)).
