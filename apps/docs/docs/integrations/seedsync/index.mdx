The SeedSync integration connects Homarr to a [SeedSync](https://github.com/nitrobass24/seedsync) instance so you can see the transfer queue, speeds, completed and failed syncs, and remote vs local storage on your dashboard.

This is the seedbox-to-home transfer layer. For the torrent client running on the seedbox itself, add a normal download-client integration (qBittorrent, Transmission, and so on) pointed at that remote URL.

### Adding the integration

<AddingIntegration />

:::info URL configuration
Use the root URL of your SeedSync web UI, for example `http://seedsync:8800`. Homarr calls `/server/status` and `/server/stream` under that URL automatically.
:::

### Secrets

Authentication is optional. If you set an API key in SeedSync **Settings → Other Settings**, send it as `X-API-Key`.
