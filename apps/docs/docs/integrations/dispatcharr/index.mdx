The Dispatcharr integration connects Homarr to a [Dispatcharr](https://dispatcharr.github.io/Dispatcharr-Docs/) instance so you can see active stream sessions, client counts, and channel/stream health.

### Adding the integration

<AddingIntegration />

:::info URL configuration
Use the root URL of your Dispatcharr instance, for example `http://dispatcharr:9191`. Homarr calls `/proxy/ts/status` and the channels/streams APIs under that URL automatically.
:::

### Secrets

Create an API key in Dispatcharr (profile or **System → Users**, depending on version) and paste it into Homarr. Homarr sends it as `X-API-Key` and `Authorization: ApiKey`.
