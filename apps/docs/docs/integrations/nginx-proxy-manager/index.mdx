The Nginx Proxy Manager integration connects Homarr to an [Nginx Proxy Manager](https://nginxproxymanager.com/) instance so you can see proxy-host status and certificate expiration on your dashboard.

### Widgets & Capabilities

<IntegrationCapabilites items={[{ widget: nginxProxyManagerWidget }]} />

### Adding the integration

<AddingIntegration />

:::info URL configuration
Use the NPM Admin URL, for example `http://nginx-proxy-manager:81`. Homarr exchanges credentials at `/api/tokens`, then reads `/api/nginx/proxy-hosts` and `/api/nginx/certificates`.
:::

### Secrets

Use the NPM admin email as the username and the account password. Homarr requests a Bearer token and does not store that token.
